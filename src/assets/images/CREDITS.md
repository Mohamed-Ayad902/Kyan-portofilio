# Project pictures

`project-*.jpg` are the pictures Kayan's company portfolio places beside each project name. They are Kayan's own material, used as supplied.

The projects page and the home slider read a list per project (`projects[slug].media` in `src/content/catalog.ts`): better pictures of the project itself go first, the portfolio picture stays last. Add a picture only when it is of that very project and its licence lets the site use it; record it below with its source, author and licence, and set its `credit` so the licence's attribution shows under the picture.
