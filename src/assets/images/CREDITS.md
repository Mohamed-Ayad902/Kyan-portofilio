# Project pictures

`project-alamein-downtown.jpg` is the picture Kayan's company portfolio places beside the Alamein Downtown Towers Project. It is Kayan's own material, used as supplied, and the home hero still shows it.

The projects page and the home slider read a list per project (`projects[slug].media` in `src/content/catalog.ts`). The first picture leads wherever one picture is shown. Record every picture below with its source, and set its `credit` so the source shows under it.

## Project media

The site is a demo. On 2026-10-24 the owner chose these pictures of each project and asked for them to be the only media shown, replacing the Pexels stock photographs and the portfolio pictures. They are press, government, developer and social media images; none is under an open licence, and permission from each rights holder has not been recorded. Before the site goes live, get that permission or replace them with Kayan's own photographs.

All are in `project-media/`, downloaded 2026-10-24, converted to sRGB JPEG and resized to at most 2000 px.
